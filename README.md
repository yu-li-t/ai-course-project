# ai-course-project
# 跨境电商综合试验区政策的DID分析

跨境电商综试区政策对企业影响的双重差分（DID）实证研究课程作业。

## 研究设计
- **政策变量**：以国务院分批批复的 8 批跨境电商综试区名单（2015–2025，181 个城市/地区）构建政策虚拟变量
  - `Treat`：企业注册地城市曾获批综试区 = 1
  - `Cross`：当年及之前已获批 = 1
- **样本**：A 股上市公司面板，2001–2024 年，5,000+ 家企业

## 主要成果

### 图1 供应链集中度年度趋势
描述性统计：客户/供应商/供应链集中度的年度均值变化（95% 置信区间）

### 图2 平行趋势检验（事件研究法）
以企业规模为被解释变量，政策前各期系数不显著异于 0（平行趋势成立），政策后系数显著为正且逐年增强（0.019 → 0.088）。
