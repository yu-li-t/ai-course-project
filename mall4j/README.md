# Mall4j 商城 - 本地部署作业

本项目为 Mall4j 开源商城的本地部署副本, 版权归原作者所有, 遵循 AGPLv3 协议(见压缩包内 LICENSE)。

## 内容
- `mall4j-source.zip`: 完整项目源码(共 1260 个文件, 已排除 node_modules/target 等构建产物)

## 运行方式
1. 下载并解压 `mall4j-source.zip`
2. 安装 Docker Desktop、Node.js 20.19+、pnpm 7+、JDK 17
3. 双击根目录 `启动商城.bat`, 等待 30-60 秒
4. 浏览器访问 http://localhost/ (H5商城) 或 http://127.0.0.1:9527/ (管理后台)
5. 后台账号 admin / 123456

详细说明见压缩包内 DEPLOY-README.md。
